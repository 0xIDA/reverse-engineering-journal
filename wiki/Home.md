## Layout (repo)

```
entries/        one folder per target — full writeup, scripts, (sometimes) annotated IDA database
notes/          target-agnostic lessons
cheatsheets/    quick reference
resources/      links, papers, tools
wiki/           markdown source published to this wiki tab
```
